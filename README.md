для Forkop. Это не официальная сборка Tachyon; проект не аффилирован с его
разработчиками. Лицензия GPL-3.0-only и авторство upstream сохранены.

профиль описан в [docs/RUST-X.md](docs/RUST-X.md). Числа и возможности в
унаследованной документации ниже относятся к upstream, если не указано иначе.
